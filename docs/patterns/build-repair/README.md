# IP-BUILD-REPAIR-01

Status: **PROTOTYPE**.

Evidence-linked diagnosis, authored repair, immutable review, constrained revision and comparison.

Authorized by GR-05 revision 2 freeze. No Golden Reference acceptance or object promotion.

Use this pattern when a learner must improve an authored professional output using evidence and a later constraint. Inputs are a deliberately weak original, bounded evidence, authored fields, review criteria and a constraint that requires connected revision. A quiz response or revealing a prepared answer cannot substitute for the output.

The sequence is evidence-linked diagnosis → authored repair → immutable first reviewed version → criterion self-review → feasibility constraint → connected revision → paired version comparison → final self-review and acknowledgment. Structure checks establish presence, bounds and state consistency; they do not establish semantic quality. A human instructional/subject reviewer evaluates the Golden Reference's depth independently.

Retain diagnosis, evidence associations, v1, current work, both reviews, unresolved follow-ups, constraint and revision rationale in a text-exportable package. Completion belongs to the interaction and is independent of saving/export. Shared session recovery is automatic; durable device saving requires explicit opt-in and truthful receipts. Narrow layouts stack corresponding before/after fields without truncation. Adopt only with an explicit case/contract and the shared ownership boundaries; cross-course approval is not implied by this prototype.
