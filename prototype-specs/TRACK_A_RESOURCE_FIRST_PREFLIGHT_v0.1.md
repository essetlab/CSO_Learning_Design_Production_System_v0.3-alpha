## Governing design learning

GR06 architecture works, but user review identifies excessive density/length: nested stages/tabs, prompts, selections and repeated authored responses. Treat it as the upper end of authored-work burden, not a production course-screen template. Track A replaces it with four supplied artifacts, three criterion rows, two short fields and one current-version reconsideration. No production changes to GR06 follow from this observation.

It does not close actual independent competence assessment, credentials, live Hub transfer, portfolio return, peer exchange, co-creation or Gate-8 final equivalence. Those remain separately governed capabilities. Track A is a capability label, not an invented GR-07 assignment.
